GENO-EVM USER’S GUIDE EVALUATION MODULE FOR GENO 0.5 RUNS LOCALLY

Geno datasheet/Evaluation module

GENO-EVM

The real Geno toolchain, compiled to WebAssembly and running in this tab. Edit the program, then test, run, check or compile it. Nothing is sent anywhere.

Output

        

      

      
Ctrl+Enter run · Ctrl+Shift+Enter test · Esc then Tab leaves the editor

    


    

      
1Board Description

      

        

          
ControlRunsNotes

          
            
Testgeno test -v Main.genoEvery example clause, with the value each failure actually produced.

            
Rungeno run --unsafe --cap … Main.genoGrants exactly the capabilities ticked under the editor. With none ticked it uses geno run --json, which grants nothing.

            
Checkgeno check Main.genoTypes, exhaustiveness and named arguments, without running anything.

            
→ Python / → JSgeno compile Main.geno --target …Shows the code generated for your program; the runtime prelude above it is folded away.

            
Opengeno.constraintsThe blocks still open at your cursor, innermost first.

          
        

      

      
The browser cannot start processes, so the sandboxed default geno run lane is replaced by the direct interpreter with explicit capabilities. Files written with fs live in memory and vanish with the tab. How the playground works.
