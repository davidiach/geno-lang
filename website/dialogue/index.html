Geno 0.5 · public preview · Apache-2.0

Plausible in.Proven out.

Geno is a programming language for code written with LLMs. The model writes. Geno makes the code show its work: examples that run, blocks that close by name, effects that need permission. Then it compiles to Python and JavaScript.

Try it in your browser
pip install geno-lang

A scripted replay. Every line Geno says is real output from geno test and geno compile for this program.

Logline

A model writes a program in seconds. Before anyone runs it, the program has to show its work: examples that pass, blocks that close, effects that were granted, cases that were handled. Geno is the language where that is the default.

Act I

Where does it end?

00:00:41

ModelI’m three blocks deep. I’ll close them when I’m done.

Genoneed_to_close=['if', 'for', 'func']

Braces and indentation are easy to lose count of when code arrives one token at a time. Geno closes every block by name: end if, end for, end func. A mismatched ending fails on its own line instead of quietly changing what the program means.

Because every opener has a named closer, Geno can tell you at any point in a partial program exactly what is still open. That is what geno constrain reports, and what a constrained decoder uses to keep a model inside the grammar.

The open-block list on the right is produced by geno.constraints for every prefix of this program.

Ask first.

      00:03:30
    

    

      
ModelI’ll read the notes file and greet the user by name.

      
GenoCapability denied: 'fs_read_text' requires '--cap fs'

    

    

      

        
Pure computation is always allowed. Files, the network, other processes, environment variables and the clock each sit behind a capability, and only the command that runs a program can grant one. A model can write fs_read_text. It cannot give itself permission to run it.

        
Grant capabilities one at a time and watch how far the program gets. Granted is not unlimited either: filesystem roots, private network addresses and response sizes stay policed.

The rest of the script.

        
Geno reads like a small, strict functional language. Immutable by default, typed at every boundary, inferred inside. Every snippet here passes geno test.

      

      

        
        
      

    

  

  

    

      
01
Algebraic data types


type Tx =
    | Deposit(amount: Int)
    | Withdraw(amount: Int)
    | Audit

func apply(balance: Int, tx: Tx) -> Int
    example 100, Withdraw(30) -> 70
    match tx with
        | Deposit(n) -> return balance + n
        | Withdraw(n) -> return balance - n
        | Audit -> return balance
    end match
end func

      
Variants carry their own fields. Matches must cover every one.

    

    

      
02
Option and ?


func first_word_length(text: Option[String]) -> Option[Int]
    example Some("geno lang") -> Some(4)
    example None -> None
    let s = text?
    let words = split(s, " ")
    return Some(length(words[0]))
end func

      
No null. ? returns early when a value is missing, and the type says it might be.

    

    

      
03
Pipelines


func squares_of_evens(xs: List[Int]) -> List[Int]
    example [1, 2, 3, 4, 5] -> [4, 16]
    return xs
        |> filter(_, fn(x: Int) -> x % 2 == 0)
        |> map(_, fn(x: Int) -> x * x)
end func

      
Data flows left to right. The _ marks where each value goes.

    

    

      
04
Comprehensions


func evens_doubled(nums: List[Int]) -> List[Int]
    example [1, 2, 3, 4] -> [4, 8]
    return [x * 2 for x: Int in nums if x % 2 == 0]
end func

      
Map and filter in one readable line.

    

    

      
05
Contracts


func factorial(n: Int) -> Int
    requires n >= 0
    ensures result >= 1
    example 5 -> 120
    example 0 -> 1
    if n <= 1 then return 1 end if
    return n * factorial(n - 1)
end func

      
Preconditions and postconditions compile into every backend.

    

    

      
06
Tuples in patterns


func describe(point: (Int, Int)) -> String
    example (0, 0) -> "origin"
    example (3, 4) -> "3,4"
    match point with
        | (0, 0) -> return "origin"
        | (x, y) -> return to_string(x) + "," + to_string(y)
    end match
end func

      
Destructure in place. A full tuple pattern covers every value.

    

    

      
07
Traits


trait Describable
    func describe(self: Self) -> String
end trait

impl Describable for Planet
    func describe(self: Planet) -> String
        example Planet("Mars", 2) -> "Mars has 2 moons"
        return f"{self.name} has {self.moons} moons"
    end func
end impl

      
Shared behaviour without inheritance. Methods carry examples too.

    

    

      
08
JSON, CSV, TOML


func json_name(text: String) -> String
    example "{\"name\": \"Ada\"}" -> "Ada"
    match json_parse(text: text) with
        | Ok(JsonObject(entries)) ->
            for entry: (String, JsonValue) in entries do
                match entry with
                    | ("name", JsonString(n)) -> return n
                    | _ -> continue
                end match
            end for
            return "unknown"
        | _ -> return "unknown"
    end match
end func

      
Parsers are built in and return values you match on, never exceptions.

    

    

      
09
Async and await


async func square(x: Int) -> Int
    return x * x
end func

func main() -> Int
    let a = await square(5)
    let b = await square(3)
    return a + b
end func

      
An Async value runs at most once, however often it is awaited.

    

    

      
10
F-strings


func greet(name: String, visits: Int) -> String
    example "Ada", 3 -> "Welcome back, Ada. Visit number 3."
    return f"Welcome back, {name}. Visit number {visits}."
end func

      
Interpolation with type-checked holes.

The numbers.

        
Compiled Geno against hand-written Python on the same problems. Geno keeps its safety checks in the compiled code and pays for them here.

        
1.60×median runtime against Python, across 53 measured problems. 45 of them, 84.9%, land at or under the 2× target.

        

          
What we don’t claim

          
The repository defines a benchmark for whether models write more correct code in Geno than in Python. No frontier-model results are published yet, so Geno makes no such claim. Why we wait
