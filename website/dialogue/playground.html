GenoPlayground

Rehearsal room.

The real Geno toolchain, compiled to WebAssembly and running in this tab. Write, test, run and compile. Nothing you type leaves your browser.

Output

        

      

      
Ctrl+Enter runs · Ctrl+Shift+Enter tests · Esc then Tab leaves the editor

    


    

      

        
What each button runs

        

          
Test
geno test -v Main.geno runs every example and shows the value each failure produced.

          
Run
geno run --unsafe --cap … with exactly the capabilities ticked. With none ticked it uses geno run --json, which grants nothing.

          
Check
geno check: types, exhaustiveness and named arguments, without running.

          
Python, JavaScript
geno compile, showing the code generated for your program.

        

      

      

        
Where the browser differs

        
A tab cannot start processes, so the sandboxed default lane of geno run is replaced by the direct interpreter with explicit capabilities. Files written with fs live in memory and disappear with the tab. Geno’s own step and time limits still apply. How the playground works
